# IMP-001 — Administração do Sistema

## Escopo do primeiro incremento

O módulo administra usuários, perfis, permissões, parâmetros e auditoria da organização.

## Entregue

- Endpoint administrativo GET /api/admin.
- Endpoint protegido PATCH /api/admin para parâmetros.
- Tela administrativa em /admin.
- Papéis conceituais do Documento Mestre.
- Matriz inicial de permissões.
- Parâmetros por organização.
- Controle de usuário ativo/inativo.
- Auditoria administrativa reaproveitando audit_events.
- Políticas RLS para administração por organização.

## Acesso

O modo demo exibe dados demonstrativos somente para inspeção da interface. Em Supabase, apenas perfil ativo com papel ADMINISTRADOR acessa a API administrativa.

## Próximo incremento

- Fluxo de convite e ativação de usuários.
- Edição de papel e status pela interface.
- Histórico de alterações de parâmetros com valor anterior.
- Gestão visual de configurações de segurança e sessão.
